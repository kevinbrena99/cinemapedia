## 🚀 Sobre el proyecto

**Cinemapedia** es una aplicación móvil desarrollada como parte de mi proceso de aprendizaje de **Flutter**.

El objetivo principal no es únicamente construir una aplicación para consultar películas, sino utilizar el proyecto como un espacio práctico para aprender y aplicar conceptos fundamentales del desarrollo con Flutter y Dart.

Durante el desarrollo voy incorporando progresivamente nuevos conocimientos, patrones y buenas prácticas.

## 📚 Formación

## 🧠 Conceptos que estoy aprendiendo

A través de Cinemapedia estoy llevando a la práctica conceptos como:

* 🐦 **Dart**

  * Sintaxis y fundamentos
  * Programación orientada a objetos
  * Null Safety
  * `Future`, `async` / `await`
  * Streams
  * Manejo de colecciones

* 💙 **Flutter**

  * Widgets
  * StatelessWidget y StatefulWidget
  * Manejo del estado
  * Navegación
  * Formularios
  * Listas y layouts
  * Consumo de APIs
  * Manejo de imágenes

* 🏗️ **Arquitectura y diseño**

  * Separación de responsabilidades
  * Patrones de diseño
  * Principios de arquitectura
  * Reutilización de componentes
  * Organización y escalabilidad del código

* 🔌 **Integración con APIs**

  * Peticiones HTTP
  * Consumo de servicios REST
  * Serialización y deserialización de información
  * Manejo de respuestas y errores

## 🎯 Objetivo

El objetivo de este proyecto es **aprender haciendo**.

Cada funcionalidad de Cinemapedia representa una oportunidad para experimentar, cometer errores, investigar y aplicar nuevos conocimientos adquiridos durante el curso.

> 💡 La aplicación irá evolucionando a medida que avance mi aprendizaje.
